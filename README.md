# Sahand Farshian | Personal Website

A personal website and portfolio for Sahand Farshian, featuring professional experience, selected projects, technical skills, education, contact information, and writing on software engineering and related topics.

**Live site:** [sfarshian.github.io](https://sfarshian.github.io)

## Technology

Built with React, TypeScript, and Vite, with Tailwind CSS for styling. The site is hosted on GitHub Pages.

## Local development

```bash
npm ci
npm run dev
```

Vite will print the local address in the terminal. To check the production build locally, run:

```bash
npm run lint
npm run build
npm run preview
```

## Deployment

Changes pushed to `main` are built and deployed to GitHub Pages through the repository’s GitHub Actions workflow.
